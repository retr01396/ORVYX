1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
In Phase 1 of the ORVYX project, we built the complete application shell and the
end-to-end 2D chest X-ray (CXR) analysis pipeline. The application loads verified
demo chest X-rays, runs the confirmed DenseNet-121 classifier (18 pathologies)
and PSPNet segmentation model (14 thoracic structures) on Apple Silicon MPS, and
renders the findings and anatomical overlays inside a custom-designed clinical
workstation interface.

All technical decisions, model parameters, and preprocessing steps match the
empirical evidence established in Phase 0 (docs/PHASE0_EVIDENCE.md) with ZERO
discrepancies.

4. KEY ARCHITECTURAL & TECHNICAL DECISIONS
--------------------------------------------------------------------------------
1. Lifespan Model Preloading:
   DenseNet-121 and PSPNet models are loaded once during FastAPI server startup
   (@asynccontextmanager lifespan), eliminating PSPNet's 22.5s cold-load time on
   user requests.

2. Strict Preprocessing Boundary Check:
   Input images are scaled to [-1024, 1024] using xrv.utils.load_image followed
   by XRayCenterCrop. Preprocessed tensors are strictly validated to lie within
   [-1024, 1024]; any out-of-bounds input raises an explicit HTTP 500 rather than
   silently degrading model predictions.

3. Compact Base64 PNG Mask Encoding:
   Raw PSPNet logits [1, 14, 512, 512] are converted via sigmoid >= 0.5 into 14
   binary masks. Masks are serialized as 1-channel PNG images encoded in Base64
   with server-computed centroids and pixel areas. This reduces payload size from
   ~7-10 MB (raw booleans) to <85 KB total per study.

4. Click-a-Finding Focal Navigation:
   Clicking an AI finding (e.g. Cardiomegaly) in the insights panel automatically
   highlights the mapped anatomical structure (e.g. Heart), animates the 2D
   viewport pan/zoom directly to that structure's centroid, and renders an
   animated crosshair reticle with coordinate labels.

5. StudyState JSON Contract:
   Fully implemented Pydantic/TypeScript contract containing study metadata,
   provenance (model names, device, runtime_ms), 18 findings with confidence
   bands (<0.3 low, 0.3-0.6 moderate, >0.6 elevated), 14 segments with centroids,
   and future-proof slots for measurements, comparison, and limitations.

6. Non-Dismissible Clinical Disclaimer:
   Persistent banner across the top: "AI-assisted research prototype — not a
   diagnostic device. All predictions require licensed radiologist review."

7. Strict Phase Scope Guardrails:
   CT volume loaders, 3D MPR viewers, and LLM routers were strictly excluded
   from Phase 1. Visibly disabled preview tabs ("3D CT Volume (Phase 2 Preview)"
   and "AI Co-Pilot (Phase 3 Preview)") are present in the workstation header.
